# VketCloud SDK 16.5.7 Release Notes

**Release Date**: April 15, 2026  
**Target Version**: VketCloud SDK 16.5.7

## Overview

VketCloud SDK 16.5.7 primarily focuses on documentation organization and template standardization. This version emphasizes stability improvements and enhanced usability.

## New Features

### Documentation Management System
- Introduction of new document version management system
- Enhanced multilingual support (Japanese and English)
- Document quality assurance through TDD (Test-Driven Development)

### Developer Experience Improvements
- Optimized MkDocs build process
- Improved navigation structure

## Improvements

### Performance
- Reduced documentation build time
- Enhanced search functionality responsiveness

### Usability
- Unified structure for release notes and changelogs
- Improved accessibility across documentation

## Bug Fixes

### Documentation-related
- Fixed broken links
- Standardized terminology and formatting
- Resolved markdown syntax errors

## Known Issues

No known issues are currently identified. If you encounter any problems, please report them via [Issues](https://github.com/HIKYY/VketCloudSDK_Documents/issues).

## Upgrade Instructions

1. Open Unity Package Manager
2. Select the VketCloud SDK package
3. Click the "Update" button in the top-right corner
4. After the update completes, rebuild your project

!!! warning "Important Note"
    We recommend backing up your existing projects before upgrading.
