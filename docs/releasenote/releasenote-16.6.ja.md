# Version 16.6.0

## HeliodorLib(ブラウザで表示されるワールドで使われているエンジン)

### 基盤システム
- アイテムカメラを使用中に画面比を変更すると変更前の画面比のまま拡張された状態になる不具合を解消

### WebXR
- VRでアイテムを掴む機能を実装
- WebXRでアンチエイリアスが効かない問題を修正
- HMDの高さを変えても、カメラやアバターが追従しない問題を修正

### UI
- 座標チャンネル移動時、ネームプレートのマイクアイコンのオンが維持される問題を修正

### HeliScript
- パーティクルでもItem.SetQuaternionが動くように対応
- 動的に低解像度テクスチャの差し替えを開始するItem.PostLoadを追加
- 指定した方向にItemの視線を向ける機能を追加
- デフォルトコンストラクタが存在しないクラスを、listの型に指定可能に改善
- レイキャストでアクティビティがヒットするように対応
