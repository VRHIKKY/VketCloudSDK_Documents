# VketCloud SDK 16.5.7 リリースノート

**リリース日**: 2026年4月15日  
**対象バージョン**: VketCloud SDK 16.5.7

## 概要

VketCloud SDK 16.5.7では、主にドキュメントの整理とテンプレートの標準化を行いました。このバージョンは安定性の向上とユーザビリティの改善に重点を置いています。

## 新機能

### ドキュメント管理システム
- 新しいドキュメントバージョン管理システムの導入
- 多言語対応の強化（日本語・英語）
- TDD（テスト駆動開発）によるドキュメント品質保証

### 開発者体験の向上
- MkDocsビルドプロセスの最適化
- ナビゲーション構造の改善

## 改善

### パフォーマンス
- ドキュメントビルド時間の短縮
- 検索機能の応答性向上

### ユーザビリティ
- リリースノートとチェンジログの構造統一
- 各種ドキュメントのアクセシビリティ向上

## バグ修正

### ドキュメント関連
- リンク切れの修正
- 表記揺れの統一
- マークダウン構文エラーの修正

## 既知の問題

現在確認されている既知の問題はありません。問題を発見された場合は、[Issue](https://github.com/HIKYY/VketCloudSDK_Documents/issues)にて報告をお願いします。

## アップグレード手順

1. Unity Package Managerを開きます
2. VketCloud SDKパッケージを選択します
3. 右上の「Update」ボタンをクリックします
4. 更新完了後、プロジェクトを再構築してください

!!! warning "注意事項"
    既存のプロジェクトをアップグレードする前に、バックアップを取ることをお勧めします。
