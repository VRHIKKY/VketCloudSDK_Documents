# 組み込み関数 - フェード

Vket Cloudのフェードを実現する関数。


***

## フェード

### hsFadeIn
`void hsFadeIn( float time )`

time秒で黒のフェードインを行う。

### hsFadeOut
`void hsFadeOut( float time )`

time秒で黒のフェードアウトを行う。

### hsWhiteFadeIn
`void hsWhiteFadeIn( float time )`

time秒で白のフェードインを行う。

### hsWhiteFadeOut
`void hsWhiteFadeOut( float time )`

time秒で白のフェードアウトを行う。
