# VKCItemPointLight

## 機能概要
ポイントライトの機能です。  
colorはポイントライトの光の色、rangeはポイントライトの光の最大有効範囲です。

!!! warning "注意"
    シーン上における最大個数は4つまでで、それ以上置いた場合、無視されます（ビルドエラーにはなりません）。

## 設定項目
![VKCItemPointLight](img/pointlight.png)

| 名称 | 初期値 | 機能 |
| :--- | :--- | :--- |
| **色** | 白(0,0,0) | RGBで指定する<br>それぞれ、0～1で指定する |
| **色強調** | false | 上記RGBに係数（Coefficient）として、加えるときの倍数を指定するか決める |
| **光の半径** | | 光が届く範囲（半径） |

### 色強調設定
| 名称 | 初期値 | 機能 |
| :--- | :--- | :--- |
| **赤** | 0 | 0~(floatで指定する）<br>「色」で指定したR値に1.0以上強調する場合に使う |
| **緑** | 0 | 0~(floatで指定する）<br>「色」で指定したG値に1.0以上強調する場合に使う |
| **青** | 0 | 0~(floatで指定する）<br>「色」で指定したB値に1.0以上強調する場合に使う |
