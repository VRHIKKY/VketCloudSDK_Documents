# sync-toc-context 出力フォーマット例

このファイルは sync-toc-context スキルの出力フォーマット詳細を定義します。

---

## サブエージェントプロンプトテンプレート

```
以下のドキュメントを読み込み、各ページの要約を生成してください。

## 対象ファイル
[カテゴリ内のファイルパスリスト]

## 出力形式
マークダウンテーブル形式で出力:

| ページ | 要約 | 参照シーン |
|--------|------|------------|
| [タイトル](パス) | 1-2行の要約 | 機能追加/不具合修正/リファクタ等 |

## 要約のガイドライン
- 各ファイルの冒頭100行程度を読み込む（limit: 100）
- 冒頭だけでは内容が不明な場合は、ファイル全体を読み込む
- このページで説明している機能/概念を簡潔に記述
- 参照シーンは以下の基準で選択（複数可）:
  - 初期セットアップ: SDK導入、環境構築、アカウント設定に関する内容
  - 機能追加: 新しいコンポーネント追加、機能実装の参考になる内容
  - 不具合修正: エラー対処、よくある問題の解決策に関する内容
  - リファクタ: コード構造の改善、ベストプラクティスに関する内容
  - パフォーマンス改善: 最適化、軽量化に関する内容
  - デバッグ: デバッグ機能、ログ出力、トラブルシューティングに関する内容
```

## summary.md

```markdown
# VketCloudSDK ドキュメント要約

> 最終更新: YYYY-MM-DD HH:MM:SS
> 処理ファイル数: XXX

## 使い方

このドキュメントは、VketCloudSDKプロジェクトの機能追加・不具合修正・リファクタを行う際の参考資料です。
「参照シーン」列を確認し、現在の作業に関連するドキュメントを参照してください。

---

## カテゴリ名

| ページ | 要約 | 参照シーン |
|--------|------|------------|
| [ページタイトル](docs/path/to/file.ja.md) | このページで説明している内容の要約。 | 機能追加, 不具合修正 |
| [別のページ](docs/path/to/another.ja.md) | 別のページの要約。 | リファクタ |

## 別のカテゴリ名

| ページ | 要約 | 参照シーン |
|--------|------|------------|
| ... | ... | ... |

（toc/file-url.md のカテゴリ構造に従って生成）
```

## 検証コマンド

```bash
# file-url.md のユニークなリンク数をカウント
grep -oE '\[.*\]\(docs/.*\.ja\.md\)' toc/file-url.md | sort -u | wc -l

# summary.md のリンク数をカウント
grep -c '\[.*\](docs/.*\.ja\.md)' toc/context/summary.md
```

### 差分確認

```bash
grep -oE 'docs/[^)]+\.ja\.md' toc/file-url.md | sort -u > /tmp/file-url-paths.txt
grep -oE 'docs/[^)]+\.ja\.md' toc/context/summary.md | sort -u > /tmp/summary-paths.txt
comm -23 /tmp/file-url-paths.txt /tmp/summary-paths.txt  # file-url.mdにのみ存在
comm -13 /tmp/file-url-paths.txt /tmp/summary-paths.txt  # summary.mdにのみ存在
```
